# Hyperlocal

> "Hyperlocal" is a placeholder name.

A multi-vendor, on-demand delivery marketplace. It connects local stores (food, grocery,
pharmacy, fashion, electronics, local services) with nearby customers, and earns through
category-wise commissions and vendor subscription plans.

**Status:** planning. No application code yet.
